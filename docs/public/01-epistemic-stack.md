# The Epistemic Stack

At the heart of Alissa lies a four-layer ontological model called the **Epistemic Stack**. Each layer answers a distinct question, and each depends on the layer beneath it. Together, they form a causal chain from observation to execution.

```
┌─────────────────────────────────────────────────────┐
│  ◆  PROJECT           What interventions do we      │
│                       COMMIT to?                    │
├─────────────────────────────────────────────────────┤
│  ◎  OBJECTIVE          What SHOULD reality become?  │
├─────────────────────────────────────────────────────┤
│  ⟁  THEORY OF CHANGE   What do we BELIEVE           │
│                        influences what?             │
├─────────────────────────────────────────────────────┤
│  ◉  OBSERVABLE          What CAN be measured?       │
└─────────────────────────────────────────────────────┘
```

## The Discipline

The stack enforces a discipline: you cannot declare an objective without first naming the observable property you intend to shift. You cannot justify a project without articulating — even tentatively — the causal belief that connects your intervention to the outcome you seek.

Each layer is distinct, reusable, and independently evaluable. This is not bureaucracy. It is epistemic hygiene.

## The Epistemic Loop

The Epistemic Stack is not a hierarchy to climb once and forget. It is a **loop** — a continuous cycle of observation, belief formation, goal-setting, intervention, and re-observation.

```
    ◉ OBSERVE                    ◉ RE-OBSERVE
    What is true? ───────────────▶ Did it change?
         │                              ▲
         ▼                              │
    ⟁ BELIEVE                    ◆ INTERVENE
    What influences what? ──────▶ Commit to bounded
         │                        action (projects,
         ▼                        milestones, tasks)
    ◎ INTEND
    What should be true?
```

This loop is the engine of organizational learning:

1. **Observe** — Register observables. Measure reality.
2. **Believe** — Articulate theories of change. Structure your causal worldview.
3. **Intend** — Declare objectives. State what reality should become.
4. **Intervene** — Commit projects. Decompose into milestones, BOWs, and tasks.
5. **Re-observe** — Measure again. Did the observables shift? Did the theory hold?

When the loop completes, the theory of change either gains confidence or is revised. Objectives are either met or re-evaluated. The organization becomes smarter — not just busier.
